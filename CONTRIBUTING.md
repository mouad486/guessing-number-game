# Contributing to Guessing Number Game

👋 Thanks for your interest in contributing! We welcome all kinds of participation — whether it’s reporting bugs, suggesting ideas, or improving the code.

---

## 🐞 Issues
- Use **Issues** only for bugs and feature requests.
- Clearly describe the problem, steps to reproduce, and expected behavior.
- For feature requests, explain why the feature would be useful.

---

## 💬 Discussions
We use **GitHub Discussions** for community interaction:
- ❓ **Q&A** → Ask questions about gameplay or setup.
- 💡 **Ideas** → Suggest new features or improvements.
- 📸 **Show & Tell** → Share screenshots or creative uses of the game.
- 🆘 **Help / Support** → Troubleshooting and technical problems.
- 📢 **Announcements** → Official updates from the maintainer.

---

## ✨ Pull Requests
- Fork the repo and create a new branch for your changes.
- Keep PRs focused — one fix or feature per PR.
- Include clear commit messages and a short description of what you changed.
- Make sure your code runs without errors before submitting.

---

## ✅ Guidelines
- Be respectful and open‑minded — this is a community we build together.
- Keep Issues focused on bugs/features so they’re easy to track.
- Use Discussions for brainstorming, feedback, or general questions.
- Follow coding best practices and keep things simple.

---

💡 Tip: If you’re unsure whether something belongs in Issues or Discussions, start with **Discussions**. Maintainers can move it if needed.
